# canids

CANIDS is a proof-of-concept **CAN Bus Intrusion Detection System (IDS)** built to demonstrate anomaly detection and security monitoring concepts in automotive networks.

## What this demonstrates
- Baseline behavior modeling for CAN traffic
- Detection of suspicious message patterns (e.g., abnormal frequency, unexpected IDs)
- Practical IDS design tradeoffs in constrained in-vehicle networks

## Intended use
Educational and research use for automotive security testing and training.
